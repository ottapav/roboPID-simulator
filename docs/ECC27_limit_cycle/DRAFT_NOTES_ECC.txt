HOW TO USE THIS DRAFT
=====================

For ECC 2027 or other IEEE conferences:
  1. Obtain the actual ieeeconf.cls from the conference website
  2. Use conference_draft_ecc.tex
  3. Regenerate all TODO-REGEN tables and figures
  4. Fill in author/affiliation/email
  5. Generate figures (see above)
  6. Check page count is still ≤ 6 pp with real figures
  7. Submit according to conference template instructions

For other venues (ADCHEM, ACC, journals):
  - The body text transfers unchanged to any LaTeX-based format
  - Use the ifacconf or elsarticle versions from the earlier generation
  - Adjust front matter as needed for the target venue

GETTING IEEECONF.CLS
====================

The real ieeeconf.cls is available from:
  - IEEE Xplore: https://www.ieee.org/conferences_events/conferences/publishing/templates.html
  - Many conference websites include it in the author kit

The shim used for page-count testing emulates the key features but the actual
class may have slightly different spacing. Expect page count to be within 1 page
of the tested 5 pages.
